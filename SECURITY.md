# Security notes

- Keep the pairing code private. It authorizes pairing the one remote device.
- Never hardcode or upload ngrok credentials in this repository.
- Messages and media are currently not end-to-end encrypted.
- Do not use this build to send highly sensitive data or precise locations unless both users understand and agree to the risks.
- To clear the app's local history, clear app storage in Android Settings. This deletes that phone's app-private data; host and client histories are stored separately.
